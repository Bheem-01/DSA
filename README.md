# DSA Practice

A collection of Data Structures and Algorithms (DSA) problems and solutions organized by topic.

## Topics

- `Arrays/`
- `Strings/`
- `LinkedList/`
- `StacksAndQueues/`
- `Hashing/`
- `SortingAndSearching/`
- `RecursionAndBacktracking/`
- `Trees/`
- `Graphs/`
- `DynamicProgramming/`
- `BitManipulation/`

## Conventions

- Keep one problem per file (e.g., `TwoSum.cpp`, `two_sum.py`, `TwoSum.java`).
- Include problem link/title and time/space complexity notes at the top of each solution.
